VELTRONIX WEBSITE STARTER
========================

This is a static, mobile-friendly educational website prototype.

PAGES
- index.html: Home
- markets.html: Market education overview
- trading.html: Future simulated-learning area (inactive)
- education.html: Educational content
- about.html: Project status and principles
- assets/style.css: Shared responsive design
- assets/app.js: Small navigation and footer script

IMPORTANT LEGAL AND SAFETY STATUS
VELTRONIX is currently a concept/prototype, not a licensed or authorised broker.
This site does not accept deposits, hold customer funds, open brokerage accounts,
collect identity/banking information, execute trades, or provide investment advice.
All visual market data is illustrative, not live prices.

A real brokerage requires qualified adult leadership, professional legal advice,
appropriate licences and permissions in every market served, compliance and
AML/KYC processes, secure technology, risk controls, and approved banking and
custody arrangements. Do not present the prototype as a regulated financial firm.

VIEW LOCALLY
Open index.html in a browser.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository.
2. Upload the files while preserving the assets folder.
3. In repository Settings, open Pages.
4. Choose deployment from the main branch and root folder.
5. Save and wait for GitHub Pages to publish.

Before using the VELTRONIX name publicly, check company-name, trademark and
domain availability in the relevant jurisdictions.
